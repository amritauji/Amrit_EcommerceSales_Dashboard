# E-commerce Sales Dashboard

This project features an interactive Power BI dashboard designed to track and analyze e-commerce sales performance and identify key customer trends.

## Key Features

- **Dynamic Data Exploration:** Leveraged filters, slicers, drill-down parameters, and customized visualizations to enable deep-dive analysis.
- **Data Modeling:** Connected and transformed complex datasets using relationships, joins, and calculated fields to support robust analytical reporting.
- **Visualization Toolkit:** Developed a comprehensive suite of visuals, including:
  - Bar, Pie, and Donut charts
  - Clustered bar charts, scatter plots, and line/area charts
  - Geographic maps and KPI scorecards
- **Business Impact:** Enhanced data-driven decision-making through:
  - Sales trend analysis
  - Category performance tracking
  - Regional analytics
